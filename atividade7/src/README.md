# Atividades TypeScript / React Native

Projeto unificado com uma tela inicial (`app/index.tsx`) que possui um botão para cada exercício. Os botões navegam para telas separadas usando Expo Router.

## Telas
- Funcionário / Empresa
- Nome e sobrenome
- Dados do aluno (inclui média e status de aprovação)
- Multiplicação de três valores
- Hello World
- Primeiro, segundo e terceiro
- Bem-vindo

## Como executar
Coloque os arquivos na estrutura de um projeto Expo com Expo Router instalado. Se ainda não tiver um projeto configurado, crie um projeto Expo Router e copie as pastas `app` e `components` para a raiz do projeto.
